------------------------------------------------
روش ۱: بدون هیچ دستری — فقط با درگ در مرورگر
(اگر Git یا Node روی کامپیوترت نصب نیست، این بهترین است)
------------------------------------------------
۱) برو به صفحه ریپوی خالی‌ات در گیت‌هاب:
   https://github.com/n3artstudio-dev/behinesaz-bargh-bushehr

۲) روی لینک «uploading an existing file» کلیک کن.

۳) این‌ها را با ماوس بکش و رها کن (Drag & Drop):
   - پوشه: src
   - پوشه: public
   - پوشه: .github
   - فایل‌ها: index.html , package.json , vite.config.ts ,
     tsconfig.json , vercel.json , netlify.toml , README.md
   (همه را یکجا انتخاب کن و بنداز وسط صفحه)

۴) پایین صفحه دکمه سبز «Commit changes» را بزن.

۵) صبر کن ۱ تا ۲ دقیقه (بالای صفحه تب «Actions» را نگاه کن،
   یک چرخش سبز می‌چرخد و تیک سبز می‌شود).

۶) برو:  Settings  ←  Pages
   کنارِ «Source» گزینه‌ی «GitHub Actions» را انتخاب کن.

۷) تمام! لینک بازی این می‌شود:
   https://n3artstudio-dev.github.io/behinesaz-bargh-bushehr/

   *** یا استقرار یک‌کلیکی روی Render (راحت‌تر، بدون تنظیم) ***
   بعد از مرحله ۴، فقط این لینک را باز کن:
   https://render.com/deploy?repo=https://github.com/n3artstudio-dev/behinesaz-bargh-bushehr
   با گیت‌هاب لاگین کن، اسم سرویس را دست نزن،
   پایین صفحه «Create Static Site» را بزن.
   چون فایل render.yaml داخل پروژه است، همه‌چیز خودش پر می‌شود.
   لینک نهایی: https://behinesaz-bargh-bushehr.onrender.com


------------------------------------------------
روش ۲: فقط یک دابل‌کلیک (اگر Git نصب است)
------------------------------------------------
۱) فایل  deploy-github.bat  را دابل‌کلیک کن.
۲) اگر پنجره لاگین گیت‌هاب باز شد، وارد شو.
۳) بعد طبق مرحله ۶ روش بالا، Pages را روی GitHub Actions بگذار.


------------------------------------------------
روش ۳: استقرار روی Vercel (فقط یک دابل‌کلیک)
------------------------------------------------
۱) یک بار از https://nodejs.org نسخه LTS را نصب کن (اگر نداری).
۲) فایل  deploy-vercel.bat  را دابل‌کلیک کن.
۳) بار اول مرورگر باز می‌شود؛ با گیت‌هاب لاگین کن (Continue with GitHub).
۴) لینک نهایی:
   https://behinesaz-bargh-bushehr.vercel.app


------------------------------------------------
راحت‌ترین حالت ممکن بدون اکانت:
به آدرس  https://app.netlify.com/drop  برو و پوشه‌ی dist
را بکش وسط صفحه؛ فوراً یک لینک زنده می‌گیری.
(برای ساختن پوشه dist کافی است در پوشه پروژه:
   npm install   و بعد   npm run build  بزنی)
